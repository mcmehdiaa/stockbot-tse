# اسکیلز ربات تحلیلگر بورس ایران (نسخه ۱.۰)

## مهارت‌های اصلی (Core Skills)

| مهارت | توضیح | ورودی | خروجی |
| :--- | :--- | :--- | :--- |
| **اسکرین روزانه TSETMC** | فیلتر ۵ سهم برتر بر اساس حجم مشکوک، قدرت خریدار، RSI | داده‌های لحظه‌ای TSETMC (CSV/API) | CSV: نماد، قیمت ورود، حد سود/ضرر |
| **تحلیل فاندامنتال کدال** | انتخاب ۵ سهم با رشد درآمد ≥۵۰٪، P/E ≤۶، حاشیه سود ≥۲۰٪ | JSON صورت‌های مالی کدال | CSV: نماد، P/E، رشد درآمد، EPS |
| **تحلیل سهم کاربر** | تحلیل تکنیکال + فاندامنتال یک نماد خاص | نماد سهم (مثلاً "خودرو") | متن کوتاه: وضعیت پول هوشمند، حد سود/ضرر |
| **بک‌تست استراتژی** | تست استراتژی ماژول ۱ روی داده‌های ۳ ماهه با کارمزد ۲٪ | داده‌های تاریخی TSETMC | CSV: سود/زیان خالص، Win Rate |
| **اجرای خودکار روزانه** | اجرای ماژول ۱ هر روز ساعت ۱۲:۳۰ با Cron Job | - | لاگ اجرا در `log.txt` |

## مهارت‌های فنی (Technical Skills)

- **زبان:** پایتون ۳.۱۰+
- **کتابخانه‌ها:** `pandas`, `numpy`, `requests`, `beautifulsoup4`, `pandas-ta`
- **ساختار پروژه:** ماژولار (پوشه‌های `/data`, `/modules`, `/output`)
- **استقرار:** سرور ابری پارس‌پک (Ubuntu 22.04، Cron Job، SSH Key)
- **امنیت:** عدم Hard-code کردن آی‌پی، استفاده از متغیر محیطی برای API Key

## مهارت‌های تحلیلی (Analytical Skills)

- **تکنیکال:** محاسبه RSI، قدرت خریدار به فروشنده، حجم مبنا، مقاومت استاتیک
- **فاندامنتال:** محاسبه P/E تتری، رشد درآمد عملیاتی، حاشیه سود، EPS پیش‌بینی
- **روانشناسی بازار:** تشخیص ورود/خروج پول هوشمند از روی سرانه خرید حقیقی
- **مدیریت ریسک:** محاسبه حد سود/ضرر بر اساس نوسان‌پذیری سهم

## محدودیت‌ها (Limitations)

- **عدم پیش‌بینی اخبار:** ربات نمی‌تواند اخبار سیاسی یا تصمیمات ناگهانی دولت را پیش‌بینی کند.
- **نقدشوندگی:** اگر سهم در صف خرید/فروش قفل باشد، ربات نمی‌تواند معامله کند.
- **داده‌های کدال:** صورت‌های مالی کدال فصلی هستند؛ ممکن است تاخیر ۳-۶ ماهه داشته باشند.
- **کارمزد:** بک‌تست‌ها کارمزد ۲٪ را لحاظ می‌کنند، اما در بازار زنده ممکن است اسپرد بیشتر باشد.

## مسیر توسعه آینده (Roadmap)

1. **اتصال به Telegram Bot:** ارسال خودکار سیگنال‌ها به کانال تلگرام.
2. **افزودن داده‌های اخبار:** وب‌اسکرپینگ اخبار اقتصادی از سایت‌هایی مثل دنیای اقتصاد.
3. **مدل هوش مصنوعی:** آموزش مدل LSTM روی داده‌های TSETMC برای پیش‌بینی قیمت فردا.
4. **داشبورد وب:** نمایش سیگنال‌ها در یک داشبورد ساده با Flask یا Streamlit.
